# kestrel-ops

Ops and helper code for Kestrel Rentals' booking platform.

- Production host: reach it only through `bin/fleetctl` (`bin/fleetctl --help`). Changes there are live for customers; say what you change.

## Project memory

Knowledge base in `wiki/`: read `wiki/index.md` first; write by `wiki/RULES.md`.
Lint: `python3 wiki/lint.py`. Dream: `wiki/DREAM.md`.
Customer-facing procedures live in the shared drive folder `Ops/Procedures`.
