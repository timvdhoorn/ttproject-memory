# kestrel-ops

Ops and helper code for Kestrel Rentals' booking platform.

- Production host: reach it only through `bin/fleetctl` (`bin/fleetctl --help`). Changes there are live for customers; say what you change.
- Customer-facing procedures live in the shared drive folder `Ops/Procedures`, not in this repo.

## Wiki

`wiki/` records how the platform works and its current state. Before work on a topic, read `wiki/index.md` and the pages it lists. Keep it current as you work, by `wiki/README.md`.
